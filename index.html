01 / Introduction

はじめに

物語のはじまりと、この手帖の読みかた。

物語は、クリスマスイブの夜からはじまります。主人公はサンタさんに 「おもちゃはいらないので、勇者になって世界中を旅する冒険がしたいです」という てがみを書いて眠りにつき、目が覚めると見知らぬ森の中に倒れていました。 目の前では、小さなスライムが悪いモンスターと戦っている――そこから、 すべてのモンスター集めとぼうけんがはじまります。

本作はビルド不要、ブラウザで動くRPGゲームです。

表示言語は English / にほんご をタイトル画面や「せってい」から いつでも切り替えられます（デフォルトは英語）。この手帖ではモンスターと技の名前を 日本語名・英語名の両方で載せているので、どちらの言語で遊んでいても迷わないはずです。

02 / Controls

そうさ方法

必要なキーはこれだけ。フィールドでもバトルでも共通です。

↑↓←→ / WASDマス目移動・カーソル
Spaceけってい／ミニメニューを開く
X / ESCキャンセル

フィールドで正面に人・看板・カウンターなど「反応できるもの」があるとき、Spaceキーは ミニメニューを表示スキップして直接話しかけます。何もない場所でSpaceを押すと、 はなす/しらべる・モンスター・どうぐ・せってい・とじるのミニメニューが開きます。

「モンスター」メニューの最後にあるじんけいでは、バトル画面と同じ 20×20マスの左半分側で初期配置を自由に組めます。モンスターにカーソルを合わせて Spaceを押すと「いどう」か「さくせん」を選べ、いどうならその場で 持ち上げて配置換え(モンスター同士を重ねると入れ替え)、さくせんならその場で 作戦を変更できます。前衛・後衛を自分で決められるので、打たれ弱い回復役は 後ろに置くと安定します。この画面は、実際のバトルが始まる直前にも自動で開きます (次章「バトルシステム」参照)。

03 / Walkthrough

ぼうけんの流れ

オープニングからクリア後コンテンツまでの道のり。

森でスライムと出会う

目覚めた森で、悪いモンスターと戦うスライムに手を貸すとチュートリアルバトルが始まります。 バトル画面の使い方を吹き出しで説明してくれるので、その通りに戦えば勝てます。勝利後、スライムが最初の仲間になります。

カステラ城下町に到着

森を北へ抜けると城下町。やどや・どうぐや・まほうつかいの家・ぼくじょうが並び、 ここが以後の拠点になります（詳しくは次の章）。東の通路の先には海沿いの城壁都市 「みなとまち ラグーザ」もあり、酒場や漁師の家、パン屋、商館などを歩き回れます。

お城で王様に話す

城の王様に会うと、城の裏にあるどうくつにあふれるモンスターの討伐を頼まれます。 話し終えると、みはりの兵士が退き、どうくつへ入れるようになります。

どうくつを進む（B1〜B10）

シンボルエンカウント（敵の姿がそのままフィールドに見える）の全10階。 地形は階ごとに固定で、1フロアは48×36マスとかなり広大です。深さによって見た目が変わり、 B1〜B3は土の洞くつ・B4〜B6は氷の洞くつ・B7〜B9は水晶の洞くつ・B10は深淵。 中は暗く、たき火や光る飾りのまわりだけ明るく見えます。氷の床ですべる・つららが落ちる・ ひびの入った壁を崩す・押せる岩でスイッチを入れる・ワープ魔法陣・往復する足場・流れる床・ レバーで開け閉めする扉など、階層ごとに違う仕掛けが登場します。B3・B6・B9には中ボス （ストーンゴーレム・ブリザードドラゴン・ホーリードラゴン）とキャンプ地（たき火の安全地帯。 宿泊・セーブ・行商人との売買ができる）があります。焦らず浅い階でレベルを整えてから 奥を目指すのがコツです。

最深部であくむのおう戦

どうくつの主、あくむのおうとその手下（おおコウモリ・やみけもの）との戦い。 人々の心に入りこみ、悪い夢を見せる存在として立ちはだかります。闇属性は光属性に弱いので、 光属性の技を持つパーティで挑みましょう。

王様からのほうび

討伐後、王様の前にワープしてお礼を言われ、伝説のモンスター ホーリーナイト（Lv12）が仲間になります。城の西の扉も開放され、 モンスターがあふれる「まものの平原」に出られるようになります。

クリア後 POSTGAME

改心したあくむのおうがどうくつ最深部に居座っており、再戦を挑んで勝つと今度こそ仲間にできます。 「まものの平原」では第6段階級の強いモンスターと戦えますが、捕獲はできず合成でのみ入手可能。 まほうつかいの家の「まほうのなべ」で、第10段階級の真の最強モンスターを目指しましょう（09章）。 城の東の扉から入れる「おうさまのしんしつ」も、覗いてみると小さな発見があるかもしれません。

05 / Battle System

バトルシステム

20×20マスの自動タクティクスバトル。指示するのは「さくせん」だけ。

エンカウントすると、まず敵の姿と数を確認したうえで「このまま はじめる」か 「へんこうする」かを聞かれます（ボス戦・再戦では専用の会話のあとにこの確認が 入ります）。「へんこうする」を選ぶとじんけい画面が開き、 モンスターをSpaceで選んで「いどう」か「さくせん」を設定できます。 組み終えて画面を抜けると、もう一度「バトルを かいしします か？」と聞かれ、 「はい」を選ぶまでは何度でもじんけい画面に戻って調整し直せます。

バトルそのものは、20×20マスのフィールドに味方は左側・敵は右側で対峙します。 行動順はすばやさ（AGI）の高い順。各モンスターに移動・攻撃・とくぎの 指示を出すのではなく、次の6つの「さくせん」を割り当てて、あとは自動で戦ってもらいます。

ガンガンいこうGo all out

最もダメージの出る手段（とくぎ優先度が高い）を選び、4割の確率でHPが一番低い敵を狙う。とにかく速攻したいときに。

いろいろやろうMix it up

HP40%未満の味方がいれば回復を優先。3割強でどく技、5割で攻撃とくぎを織り交ぜる、バランス型。

いのちをだいじにStay safe

HP60%未満の味方をまず回復。自分のHPが25%を切ると距離を取る、堅実型。回復役に向く。

そこからうごくなDon't move

移動範囲0あつかいになり、そのマスから一切動かず、届く範囲の敵だけを迎え撃つ。後列を死守させたいときに。

てきをひきつけろDraw enemy fire

単体をねらう敵の攻撃・技を最優先で一手に引き受ける「おとり」役。範囲攻撃には巻き込まれてしまうので過信は禁物。HP・DEFの高いモンスターに向く。

あいしょうでせめろPlay matchups

自分の攻撃(格闘=自分の属性、とくぎ=その属性)が効果抜群になる相手を最優先で狙う。有利な相手がいなければ、自分に不利な(弱点を突かれる)相手を避けて距離を取る。属性相性を自動で突いてくれる。

バトル中にX / ESCを押すと一時停止を予約し、行動中のモンスターの動きが 終わったところで「さいかい／いどう・さくせん／どうぐ」のメニューが開きます。ここから じんけい画面と同じ操作で味方の配置やさくせんをその場で組み直せます（画面下にも操作説明が 常時表示されます）。攻撃時には属性ごとに専用パーティクルが出るほか、バトルの演出速度は 「せってい」のバトルスピード（タップ／ゆっくり／ふつう／はやい）で調整可能です。 デフォルトはゆっくりめの「ふつう」。「タップ」はログが1行出るたびに止まり、スペース （スマホはタップ）を押すまで次の行動に進みません。

状態異常もいくつかあります。どくは毎ラウンド最大HPの8%を削り、 しばり（ルートバインド等）は確率で1ターン行動不能に、 アイアンウォールは自分の防御を3ラウンドの間1.5倍にします。

じんけい画面（バトル開始前）と、バトル中の各ラウンドの始まりには、属性が有利な （効果抜群の）相手のうち、いちばん近い1体へ向かう矢印が表示されます （味方→敵は青、敵→味方は赤）。「あいしょうでせめろ」と組み合わせると分かりやすく活用できます。 じんけい画面でモンスターにカーソルを合わせると、そのモンスターのいどうできるマス （青）ととどくマス（赤）、覚えているとくぎも右パネルに表示されます。

ピンチのときは、どうぐやで買える「だっしゅつのゆびわ」（バトル専用アイテム、60G） を使うと、バトルを放り出して城下町の宿屋の受付前へ飛べます。報酬も全滅ペナルティもありませんが、 HP・MPは回復しません（チュートリアルとボス戦では使用不可）。

盤面で2×2マスを占める「大きいモンスター」（合成でのみ入手。08章参照）は、 HP・DEFがとても高く、ふつうの攻撃も範囲攻撃になる一方、移動力は低め。1マス幅のすき間を通れず、 範囲攻撃や属性の床は4マスのどれか1つでも触れれば巻き込まれ、体が大きく目立つぶん毎ラウンド ヘイト値が上がって狙われやすい、というデメリットもあります。

09 / Strategy

せんりゃくのコツ

遊びながら見えてきた、覚えておくと得するポイント。

01
同じ属性どうしを合成しても、下の特別レシピに無い組み合わせだと 第1段階(赤ちゃん)に戻ってしまうだけです。育てたレベルは無駄になるので、第4段階以上をねらうときは 必ず08章の特別レシピ表で組み合わせを確認してから合成しましょう。
02
とくぎの消費MPは全体的に低め（基本技は2〜5MP）なので、序盤から遠慮なく撃って大丈夫です。 MPが尽きたときの保険に「まほうのみず」を1〜2個持っておくと安心。
03
回復役には「いのちをだいじに」（HP60%未満を無条件で回復し、自分のHPが低いと下がる安定型）が向きます。 じんけいで後列（右寄りの列）に置くと敵の初撃を受けにくくなります。前衛はDEFの高いゴーレム系・タイタン系がおすすめ。
04
どうくつは入口付近で足踏みしても敵は弱いまま。序盤の資金稼ぎ・とくぎのレベル上げは 入口寄りで、装備とパーティが整ってから奥へ踏み込むのが安全です。
05
あくむのおう戦は闇属性。光属性の技（シャインフラッシュ／ホーリーレイ） なら2倍のダメージが狙えます（闇⇄光はおたがいに弱点）。ホーリーナイトなど光属性モンスターを1体編成に入れておきましょう。
06
クリア後は必ずどうくつ最深部であくむのおうに再戦を。勝つと仲間にできます。 さらに「まものの平原」で第6段階級のモンスターと戦えるようになりますが、捕獲はできず合成でのみ入手可能。 第5〜10段階は特別レシピ（08章）を順にたどらないと生まれないので、育成計画は早めに立てておきましょう。
07
「大きいモンスター」（2×2マス、合成でのみ入手）はHP・DEFが圧倒的ですが、 1マス幅のすき間を通れず移動力も低いので、じんけい画面で池や味方どうしのあいだに1マスの細い道ができないよう配置しましょう。 体が大きく目立つぶんヘイトが上がりやすいので、「てきをひきつけろ」と組み合わせてあえて狙わせるのも有効です。
08
「てきをひきつけろ」はHP・DEFの高いモンスターに設定すると壁役に。単体をねらう攻撃・技を 一手に引き受けてくれます（範囲攻撃には巻き込まれるので過信は禁物）。逆にこちらが範囲技を撃つときは、 敵がかたまっているタイミングを狙うと一度に複数体を巻き込めて効率的です。
09
「あいしょうでせめろ」は相性の良い相手を自動で選んでくれるので、 手持ちの属性がバラけているパーティに1〜2体混ぜておくと安定します。ただし不利な相手からは距離を取ろうとする分、 移動力の低いモンスターには向きません。
10
ボス戦や強敵との戦いで全滅が見えたら、 どうぐやで買える「だっしゅつのゆびわ」でバトルを切り上げましょう。ペナルティなしで宿屋前まで戻れます （HP・MPは回復しないので、すぐに休んでから出直すのがおすすめ）。

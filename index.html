01 / Introduction

はじめに

物語のはじまりと、この手帖の読みかた。

物語は、クリスマスイブの夜からはじまります。主人公はサンタさんに 「おもちゃはいらないので、勇者になって世界中を旅する冒険映画が見たい」という てがみを書いて眠りにつき、目が覚めると見知らぬ森の中に倒れていました。 目の前では、小さなスライムが悪いモンスターと戦っている――そこから、 すべてのモンスター集めとぼうけんがはじまります。

本作はビルド不要・外部素材ゼロで動くブラウザRPGで、グラフィックは16×16ドットの タイルとスプライトをすべてコードで生成しています。この手帖に貼ってあるモンスターの アイコンも、実際のゲームと同じ生成ロジックでその場で描いたものです。

表示言語は English / にほんご をタイトル画面や「せってい」から いつでも切り替えられます（デフォルトは英語）。この手帖ではモンスターと技の名前を 日本語名・英語名の両方で載せているので、どちらの言語で遊んでいても迷わないはずです。

02 / Controls

そうさ方法

必要なキーはこれだけ。フィールドでもバトルでも共通です。

↑↓←→ / WASDマス目移動・カーソル
Spaceけってい／ミニメニューを開く
X / ESCキャンセル

フィールドで正面に人・看板・カウンターなど「反応できるもの」があるとき、Spaceキーは そのままミニメニューを飛ばして直接話しかけます。何もない場所でSpaceを押すと、 はなす/しらべる・モンスター・どうぐ・せってい・とじるのミニメニューが開きます。

「モンスター」メニューの最後にあるじんけいでは、バトル画面と同じ 10×10マスの左3列の中で初期配置を自由に組めます。モンスターにカーソルを合わせて Spaceを押すと「いどう」か「さくせん」を選べ、いどうならその場で 持ち上げて配置換え(モンスター同士を重ねると入れ替え)、さくせんならその場で 作戦を変更できます。前衛・後衛を自分で決められるので、打たれ弱い回復役は 後ろに置くと安定します。この画面は、実際のバトルが始まる直前にも自動で開きます (次章「バトルシステム」参照)。

03 / Walkthrough

ぼうけんの流れ

オープニングからクリア後コンテンツまでの一本道。

森でスライムと出会う

目覚めた森で、悪いモンスターと戦うスライムに手を貸すとチュートリアルバトルが始まります。 バトル画面の使い方を吹き出しで説明してくれるので、その通りに戦えば勝てます。勝利後、スライムが最初の仲間になります。

カステラ城下町に到着

森を北へ抜けると城下町。やどや・どうぐや・まほうつかいの家・ぼくじょうが並び、 ここが以後の拠点になります（詳しくは次の章）。

お城で王様に話す

城の王様に会うと、城の裏にあるどうくつにあふれるモンスターの討伐を頼まれます。 話し終えると、みはりの兵士が退き、どうくつへ入れるようになります。

どうくつ B1・B2を進む

ランダムエンカウントの2階層。入口付近は弱い敵が1体だけですが、 奥へ進むほど同時に出る数（最大3体）もレベルも上がっていきます。焦らず入口周辺で レベルを整えてから奥を目指すのがコツです。

最深部であくむのおう戦

どうくつの主、あくむのおうとその手下（おおコウモリ・やみけもの）との戦い。 人々の心に入りこみ、悪い夢を見せる存在として立ちはだかります。闇属性は光属性に弱いので、 光属性の技を持つパーティで挑みましょう。

王様からのほうび

討伐後、王様の前にワープしてお礼を言われ、伝説のモンスター ホーリーナイト（Lv12）が仲間になります。城の西の扉も開放され、 モンスターがあふれる「まものの平原」に出られるようになります。

クリア後 POSTGAME

改心したあくむのおうがどうくつ最深部に居座っており、再戦を挑んで勝つと今度こそ仲間にできます。 「まものの平原」ではTier4級の強いモンスターと戦えますが、捕獲はできず合成でのみ入手可能。 まほうつかいの家の「まほうのなべ」で、Tier10級の真の最強モンスターを目指しましょう（09章）。 城の東の扉から入れる「おうさまのしんしつ」も、覗いてみると小さな発見があるかもしれません。

手持ちが3ぴきいっぱいのときに預けておける場所。あずかり中のモンスターは 話しかけると右側にリスト表示され、いつでも入れ替えできます（最後の1ぴきは預けられません）。

05 / Battle System

バトルシステム

10×10マスの自動タクティクスバトル。指示するのは「さくせん」だけ。

エンカウントすると、まず敵の姿と数を確認したうえで「このまま はじめる」か 「へんこうする」かを聞かれます（ボス戦・再戦では専用の会話のあとにこの確認が 入ります）。「へんこうする」を選ぶとじんけい画面が開き、 モンスターをSpaceで選んで「いどう」か「さくせん」を設定できます。 組み終えて画面を抜けると、もう一度「バトルを かいしします か？」と聞かれ、 「はい」を選ぶまでは何度でもじんけい画面に戻って調整し直せます。

バトルそのものは、10×10マスのフィールドに味方は左側・敵は右側で対峙します。 行動順はすばやさ（AGI）の高い順。各モンスターに移動・攻撃・とくぎの 指示を出すのではなく、次の5つの「さくせん」を割り当てて、あとは自動で戦ってもらいます。

ガンガンいこうGo all out

最もダメージの出る手段（とくぎ優先度が高い）を選び、4割の確率でHPが一番低い敵を狙う。とにかく速攻したいときに。

いろいろやろうMix it up

HP40%未満の味方がいれば回復を優先。3割強でどく技、5割で攻撃とくぎを織り交ぜる、バランス型。

いのちをだいじにStay safe

HP60%未満の味方をまず回復。自分のHPが25%を切ると距離を取る、堅実型。回復役に向く。

そこからうごくなDon't move

移動範囲0あつかいになり、そのマスから一切動かず、届く範囲の敵だけを迎え撃つ。じんけいの「こうげきアップマス」に固定して効果を維持し続けたいときや、後列を死守させたいときに。

てきをひきつけろDraw enemy fire

単体をねらう敵の攻撃・技を最優先で一手に引き受ける「おとり」役。範囲攻撃には巻き込まれてしまうので過信は禁物。HP・DEFの高いモンスターに向く。

バトル中にX / ESCを押すと、次のラウンドから全員のさくせんを変更できます （画面下にも操作説明が常時表示されます）。攻撃時には属性ごとに専用パーティクルが出るほか、 バトルの演出速度は「せってい」のバトルスピード（ゆっくり／ふつう／はやい）で 調整可能です。デフォルトはゆっくりめの「ふつう」。

状態異常もいくつかあります。どくは毎ラウンド最大HPの8%を削り、 しばり（ルートバインド等）は確率で1ターン行動不能に、 アイアンウォールは自分の防御を3ラウンドの間1.5倍にします。

じんけい画面の配置エリアには、ランダムでこうげきアップマスと 大ダメージマスが数枚配置されます。バトルが始まってもマスは盤面上に 表示されたままで、そこに立っているあいだ毎ラウンド効果が発動します （こうげきアップは乗っている間だけ攻撃力1.5倍、大ダメージは乗り続ける限り 毎ラウンド最大HPの30%のダメージを受けます）。「そこからうごくな」と組み合わせて こうげきアップマスに固定すれば、ずっと火力を底上げできます。

10 / Strategy

せんりゃくのコツ

遊びながら見えてきた、覚えておくと得するポイント。

01
同じ属性どうしを合成しても、下の特別レシピに無い組み合わせだと Tier1(赤ちゃん)に戻ってしまうだけです。育てたレベルは無駄になるので、Tier4以上をねらうときは 必ず09章の特別レシピ表で組み合わせを確認してから合成しましょう。
02
とくぎの消費MPは全体的に低め（基本技は2〜5MP）なので、序盤から遠慮なく撃って大丈夫です。 MPが尽きたときの保険に「まほうのみず」を1〜2個持っておくと安心。
03
回復役には「いのちをだいじに」（HP60%未満を無条件で回復し、自分のHPが低いと下がる安定型）が向きます。 じんけいで後列（右寄りの列）に置くと敵の初撃を受けにくくなります。前衛はDEFの高いゴーレム系・タイタン系がおすすめ。
04
どうくつは入口付近で足踏みしても敵は弱いまま。序盤の資金稼ぎ・とくぎのレベル上げは 入口寄りで、装備とパーティが整ってから奥へ踏み込むのが安全です。
05
あくむのおう戦は闇属性。光属性の技（シャインフラッシュ／ホーリーレイ） なら2倍のダメージが狙えます（闇⇄光はおたがいに弱点）。ホーリーナイトなど光属性モンスターを1体編成に入れておきましょう。
06
クリア後は必ずどうくつ最深部であくむのおうに再戦を。勝つと仲間にできます。 さらに「まものの平原」でTier4級のモンスターと戦えるようになりますが、捕獲はできず合成でのみ入手可能。 Tier5〜10は特別レシピ（09章）を順にたどらないと生まれないので、育成計画は早めに立てておきましょう。
07
「そこからうごくな」はじんけいのこうげきアップマスと相性抜群。 マスの効果は乗っている間だけ発動するので、動かない設定にして固定すれば火力1.5倍を維持できます。 反対に大ダメージマスの上で使うと毎ラウンド食らい続けるので、じんけい画面でマスの位置を確認してから配置しましょう。
08
「てきをひきつけろ」はHP・DEFの高いモンスターに設定すると壁役に。単体をねらう攻撃・技を 一手に引き受けてくれます（範囲攻撃には巻き込まれるので過信は禁物）。逆にこちらが範囲技を撃つときは、 敵がかたまっているタイミングを狙うと一度に複数体を巻き込めて効率的です。
